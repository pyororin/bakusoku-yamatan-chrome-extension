# やまたん爆速予約 (Yamatan Instant Booking)

山小屋予約サイト「やまたん」(`https://www.yamatan.net/`) の予約カレンダー上に **「即予約」ボタン** を追加し、ダイアログ操作・確認ページの入力・最終ボタン押下までを自動化する **非公式** Chrome 拡張機能 (Manifest V3) です。

> 本ツールは「やまたん」の運営とは無関係の個人製作物です。利用前に必ず [注意事項・免責](#注意事項免責) を確認してください。

## 特長

- **ログイン状態の判定**: ページ内に「ログアウト」リンクがある場合のみ動作します。
- **「即予約」ボタンの挿入**: カレンダー(FullCalendar)の各予定のタイトルが `×/` で始まらないもの(=予約不可でないもの)の右側に、**紫色**の「即予約」ボタンを追加します。`MutationObserver` で DOM 変化を監視するため、月移動などの画面更新にも追従します。
- **ワンクリック自動予約**: ボタン押下で以下を順に実行します。
  1. 元のカレンダー予定リンクをクリックして予約ダイアログを開く
  2. プランのプルダウンで **2番目の選択肢**(選択肢が1つなら最後の項目)を選択
  3. 設定した男性/女性の人数分だけ「＋」ボタンを押下
  4. 「予約へ進む」ボタンで確認ページへ遷移
  5. 確認ページの質問欄 Q1〜Q4 に設定内容を入力
  6. 「最終確定まで実行する」が有効なら、最終確定ボタンをクリック
- **リトライ**: ダイアログ〜確認ページの処理は失敗時に最大 2 回(500ms 間隔)再試行します。
- **デバッグモード**: 「最終確定まで実行する」をオフにすると、最終ボタンを押さずに入力まで行って止まります(画面右上にトースト通知)。
- **事前情報チェック**: マイページのプロフィール必須項目とクレジットカード登録の有無を、バックグラウンドのタブで確認します。
- **設定のエクスポート/インポート/全クリア** に対応します。

## 技術スタック

- Chrome 拡張機能 Manifest V3 (Service Worker / Content Script / Options Page)
- Vanilla JavaScript(ビルド工程・外部ライブラリなし)
- `chrome.storage.sync`(設定保存)、`chrome.scripting` / `chrome.tabs`(事前情報チェック)

## 動作要件

- Google Chrome(Manifest V3 対応版)
- 「やまたん」のアカウント(ログイン済みであること)
- 予約に必要なプロフィール・クレジットカードがマイページに登録済みであること

## セットアップ

### リリースから導入する場合

1. [リリースページ](https://github.com/pyororin/bakusoku-yamatan-chrome-extension/releases) から最新の ZIP をダウンロードして解凍
2. Chrome で `chrome://extensions` を開き、右上の「デベロッパー モード」をオン
3. 「パッケージ化されていない拡張機能を読み込む」で解凍したフォルダを選択

### ソースから導入する場合

このリポジトリを clone し、リポジトリのルート(`manifest.json` のあるフォルダ)を上記手順 3 で選択します。

## 使い方

1. ツールバーの拡張機能アイコン(またはオプションページ)から設定画面を開きます。
2. 各項目を入力して「保存」を押します。
3. 「やまたん」にログインし、予約カレンダーを開きます。
4. 予約可能な枠の横に表示される紫色の「即予約」ボタンを押すと、以降が自動で実行されます。処理中はボタンが「処理中...」(灰色)になり、完了後は元の表示に戻ります(戻り時の色は赤になります)。処理が終わるまでページを閉じないでください。

## 設定

| 項目 | 内容 |
|---|---|
| Q1 | お客様全員の名前・年齢・性別(**必須**) |
| Q2 | 前日の宿泊地(**必須**) |
| Q3 | 翌日歩くルート・目的地(**必須**) |
| Q4 | 食事に関する特別な要望(任意) |
| 予約人数 | 男性/女性それぞれ 0〜9 名(初期値: 男性1・女性0) |
| 最終確定まで実行する | オフで最終ボタンを押さない |

- Q1〜Q3 が未入力だと実行時にエラーになります。
- 設定は `chrome.storage.sync` に保存されます(Chrome アカウントで同期され得ます)。個人情報を含むため、**エクスポートした JSON の取り扱いにご注意ください**。リポジトリ等へ公開しないでください。
- 「事前情報チェック」は `/user/mypage/profile` と `/user/mypage/card` を非表示タブで開いて確認します。プロフィールは `required` 項目の未入力を検出(パスポート欄は除外)、カードはマスク表示(`****`)の有無で判定します。

## ファイル構成

```
manifest.json   拡張機能定義(権限: storage / scripting / tabs、対象: https://www.yamatan.net/*)
content.js      即予約ボタン挿入と予約フロー自動化
utils.js        waitForSelector / waitForEnabled / sleep / トースト / 設定読込
background.js   事前情報チェック(別タブでスクレイピング)
options.html/.css/.js  設定画面(保存・エクスポート・インポート・クリア)
```

- 「やまたん」の HTML 構造(クラス名・ID・`data-test-id` 等)に強く依存しています。サイト改修により動作しなくなる可能性があります。

- ネットワーク状況によっては処理に時間がかかります。
